# Модулі Ейви 2.0

Тут лежать **пакети модулів** для голосової помічниці «Ейва 2.0» (Windows 10 / 11). Коду самої Ейви тут немає — лише пакети модулів.

Модуль — це опис і правила для однієї програми чи групи програм (Telegram, Discord, Spotify, Steam, Офіс, VS Code…):

- `manifest.json` — що це за модуль, назва, категорія, як знайти програму на ПК;
- `rules.json` — правила й заборони (що Ейві можна, а чого не можна робити в цій програмі);
- `schema/` — будова службової бази модуля (журнал дій, без особистих даних);
- `scripts/` — перелік дій модуля.

## Як Ейва ними користується

1. Після встановлення Ейви всі модулі вимкнені.
2. Власник вмикає модуль у «Налаштування → Інтеграції». Якщо пакета ще немає на ПК, Ейва завантажує його звідси.
3. Ейва бере адресу пакета й його SHA-256 з каталогу [`modules-index.json`](modules-index.json). Якщо SHA-256 завантаженого архіву не збігається, пакет не встановлюється й нічого не змінюється.
4. Ейва завантажує пакети лише з цього репозиторію (`https://github.com/kurv1d/eva2-modules/releases/download/…`). Будь-які інші адреси вона відкидає.
5. Раз на добу Ейва перевіряє, чи є нові версії модулів. Якщо є, в «Інтеграціях» з'являється «Є нова версія — оновити?». Модуль оновлюється лише після натискання «Оновити».

## Де пакети

Архіви `<id>-<версія>.zip` прикріплені до [релізів](https://github.com/kurv1d/eva2-modules/releases). Каталог `modules-index.json` містить для кожного модуля id, назву, категорію, версію, адресу архіву, SHA-256, розмір і список файлів.

Архіви збираються детерміновано: якщо модуль не змінився, його SHA-256 теж не змінюється. Перед публікацією збирач перевіряє, що в пакетах немає баз даних, журналів, ключів, токенів і шляхів з іменем користувача.
